필라픽 PilaPick PWA 패키지 (시연용 프로토타입)

1) zip을 풀고, 폴더 안의 파일들(index.html, manifest.webmanifest, sw.js, icon-*.png, README.txt)을
   GitHub 저장소 맨 위(루트)에 올리세요. 같은 이름 파일은 덮어쓰기 하세요.
2) Settings > Pages 에서 main 브랜치 /(root) 로 배포하세요. 주소는 https:// 여야 합니다.
3) 휴대폰 크롬: 메뉴 > 홈 화면에 추가 / 앱 설치, 아이폰 사파리: 공유 > 홈 화면에 추가
4) 예전 화면이 보이면 Ctrl+Shift+R 강력 새로고침(또는 사이트 데이터 삭제)을 하세요.
5) 데이터는 각 기기 브라우저에만 저장됩니다. 실제 센터·회원 정보는 넣지 마세요.
